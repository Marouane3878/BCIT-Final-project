# Spartan Fight Club Website

https://marouane3878.github.io/BCIT-Final-project/

A responsive martial arts gym website built with **HTML, CSS, and JavaScript**. The project presents a fictional fight club called **Spartan Fight Club**, featuring programs for striking, Brazilian Jiu-Jitsu, and wrestling.

The website includes a homepage, navigation menu, program highlights, testimonials, call-to-action sections, and contact information. It is designed to give visitors a clear overview of the gym and encourage them to book a free trial class.

## Project Overview

**Spartan Fight Club Website** is a front-end web development project created to practice building a structured, responsive, and user-friendly multi-page website. The homepage includes a hero section, program cards, member testimonials, and a final call-to-action for booking a free trial class. The HTML also links to external CSS, JavaScript, images, and Google Fonts. :contentReference[oaicite:0]{index=0}

## Features

- Responsive homepage layout
- Header navigation menu
- Burger menu for smaller screens
- Hero section with call-to-action button
- Program cards for:
  - Striking
  - Jiu Jitsu
  - Wrestling
- Testimonials section
- Footer with quick links, contact details, and social links
- Linked CSS stylesheet
- Linked JavaScript menu file
- Google Fonts integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
